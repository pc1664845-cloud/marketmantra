# MarketMantra — safer educational starter site

A static, responsive Indian finance education website for GitHub Pages.

## Files
- `index.html` — homepage and calculators
- `style.css` — styling
- `script.js` — browser-side calculator logic
- `privacy.html` — starter privacy notice
- `disclaimer.html` — financial information disclaimer
- `terms.html` — starter terms and conditions
- `affiliate-disclosure.html` — commercial relationship disclosure
- `contact.html` — must be completed with verified operator contact details

## Publish / update on GitHub Pages
1. Open https://github.com/pc1664845-cloud/marketmantra
2. Click **Add file → Upload files**.
3. Upload all files in this folder to the repository root. Choose **Replace** if GitHub asks about existing files.
4. Commit changes to `main`.
5. If GitHub Pages is already enabled, wait for the new deployment. Otherwise go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.

## Mandatory before public launch
- Replace the Contact page action-required message with a real, monitored contact address and the operator identity/details appropriate to the actual business.
- Have an Indian lawyer review the actual website, business structure, services, disclosures and applicable laws.
- Do not add stock tips, buy/sell calls, personalised portfolio recommendations, paid research, trading signals or advisory services without first obtaining specialist advice on SEBI registration and other applicable requirements.
- Keep market data blank or clearly labelled until you have a reliable source and permission/licence to display it.
- Do not claim guaranteed returns, risk-free investments or assured profits.
- Keep the newsletter form as a demo unless a compliant provider, privacy notice and suitable consent flow are implemented.
- Before adding analytics, advertising or affiliate tracking, update the privacy notice and implement applicable disclosures/consent and provider requirements.
- Clearly label affiliate, sponsored and advertising content near each placement; comply with each programme's rules and applicable ASCI/consumer protection requirements.
- Publish only original content or material you have permission to use.
- Review Google AdSense policies and site eligibility before applying. Approval is not guaranteed.

## Current technical behaviour
- SIP, EMI and FD calculators run in the visitor's browser and do not intentionally submit the entered calculator values to a MarketMantra backend.
- Newsletter form is a non-functional demo and does not store or transmit email addresses.
- No market-data API, user login, payment, analytics or advertising tags are included.
- GitHub Pages hosting may process technical request information; see GitHub's privacy documentation.
