# MarketMantra

A responsive, light-theme Indian personal finance and market tools website built with plain HTML, CSS and JavaScript. Designed for GitHub Pages.

## Files
- `index.html` — homepage and calculators
- `style.css` — responsive light-theme design
- `script.js` — calculator and navigation interactions
- `privacy.html` — starter privacy policy
- `disclaimer.html` — financial and affiliate disclaimer

## Publish with GitHub Pages
1. Open your public repository named `marketmantra`.
2. Choose **Add file → Upload files**.
3. Upload all five website files from this folder (you can keep the existing README.md).
4. Commit to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. Your site should appear at `https://pc1664845-cloud.github.io/marketmantra/`.

## Before monetising
- Replace the demo market placeholders with a reliable, permitted market-data source. The current page does not display live prices.
- Connect the newsletter form to a real email service before collecting addresses.
- Add genuine, original articles and useful content before applying to advertising or affiliate programmes.
- Replace `hello@marketmantra.in` with an email address you control.
- Review and customise the privacy policy and disclaimer for the services you actually enable.
- Add affiliate links only after approval by each programme, and clearly disclose commissions.
- Do not add Google AdSense code until the account and site are approved.

## Important
The calculators are educational estimates, not financial advice. SIP projections assume monthly contributions and a constant illustrative return; FD uses quarterly compounding; EMI uses a standard reducing-balance formula. Actual product terms and outcomes can differ.
